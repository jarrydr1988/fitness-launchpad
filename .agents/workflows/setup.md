# Fitness Launchpad Setup

This project uses modern web technologies (Vite, React, Tailwind CSS) and uses Bun as its package manager (indicated by `bun.lockb`).

## Installation
Run the following to install all project dependencies:
// turbo
```bash
bun install
```

## Running the App
Start the local development server:
// turbo
```bash
bun run dev
```
